Arrow Button Mapper は、Webページ上の「前へ」「次へ」などのリンクやボタンを、キーボードの ← / → キーで操作できる Chrome 拡張機能です。

電子書籍ビューア、画像ギャラリー、検索結果、社内ツールなど、矢印キー操作に対応していないページでも、普段どおりのページ送りを実現できます。

ポップアップから左右をまとめて登録できます。戻る、進むの順にページ上のリンクやボタンをクリックしてください。片方だけ登録することもできます。対象を右クリックし、メニューから登録する方法や、CSS セレクタを直接入力する方法もあります。

- ページ上のリンク・ボタンをクリックして、左右キーの操作として記憶
- 戻る・進むを連続で登録。片側のスキップややり直しにも対応
- リンク・ボタンの右クリックメニューから、← または → に登録
- URL ごとに「戻る」「進む」の操作対象を登録
- 複数の設定が一致する場合は、より具体的な URL 条件を優先
- URL パターンと CSS セレクタを手動で編集
- 設定を JSON でエクスポート・インポート
- 入力欄や編集可能な場所では、通常の矢印キー操作を妨げない設計

設定は Chrome の同期ストレージに保存されます。閲覧履歴、ページ内容、設定内容を開発者のサーバーへ送信することはありません。

一部のページや iframe 内の要素では利用できません。サイトの構造が変わった場合は再登録が必要になることがあります。
