Arrow Button Mapper lets you use the ← and → keys to click links and buttons on web pages.

Use it for previous/next navigation in readers, galleries, search results, and other pages that do not already support arrow-key navigation.

To set it up, open the popup and choose Record Back and Next. Click the Back button on the page, then the Next button. You can skip a direction or record each direction separately. You can also right-click a link or button and assign it from the Arrow Button Mapper menu, or enter a CSS selector manually.

Features:
- Record a page link or button by clicking it, without following the link during recording.
- Record both directions in one session, with skip, start-over, and cancel controls.
- Assign a link or button from its right-click menu.
- Save separate action pairs for different URL patterns.
- Use the most specific matching URL pattern when several settings apply.
- Edit URL patterns and CSS selectors manually.
- Export and import settings as JSON.
- Keep normal arrow-key behavior in input fields and editable areas.

The extension UI follows your Chrome language: Japanese for Japanese, English otherwise. You can map buttons on pages in any language.

Settings are stored in Chrome sync storage and may sync according to your Chrome settings. The developer does not receive your browsing history, page contents, or settings. No external AI or analytics service is used.

Some pages and elements inside iframes are not supported. If a website changes its structure, you may need to record the target again. This extension maps page elements; it does not replace the browser's history Back and Forward commands.
