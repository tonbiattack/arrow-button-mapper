# Store listing settings

## Category

`Productivity`（生産性）

## Language

`Japanese`（日本語）

## Upload assets

| 用途 | ファイル | 要件 |
| --- | --- | --- |
| Store icon | `assets/store-icon-128.png` | 128 × 128 PNG |
| Small promotional tile | `assets/promo-tile-440x280.png` | 440 × 280 PNG |
| Marquee promotional tile | `assets/marquee-1400x560.png` | 1400 × 560、24ビット PNG |
| Screenshots | `assets/screenshots/1.png`、`2.png`、`3.png` | 各 1280 × 800、24ビット PNG |

アップロード前に、画像が公開するバージョンの実際の UI を示し、URL、個人情報、認証情報を含まないことを確認する。詳細は [screenshots.md](../screenshots.md) を参照する。
