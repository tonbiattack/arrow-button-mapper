# Data usage / Limited Use

この画面は選択式であり、自由記述欄ではない。公開時点の Dashboard の設問と実装を照合して回答する。

## 処理するデータ

- ユーザーがクリック記憶または右クリック登録を行ったページの URL（オリジンとパスを URL パターンとして保存）
- ユーザーが選択したリンクまたはボタンから作った CSS セレクタ
- セレクタを生成するために参照する対象要素の ID、属性、リンク先など。右クリックした候補要素はページ内のメモリに一時保持する
- 拡張機能の有効・無効状態
- ユーザーが明示的にインポートした JSON 設定ファイル

## 処理しないデータ

- フォーム入力、認証情報、Cookie を設定として収集する処理
- 操作していないページの URL を設定として保存する処理（URL 条件の照合には現在のページ URL を使用する）
- 外部サーバーへ送信するデータ、広告・分析・追跡データ

## 回答時の確認事項

1. 保存する URL パターンが Dashboard の「web history」等の分類に該当するか、現在の設問文に照らして確認する。該当する場合は、収集目的を「ユーザーが指定したページ操作の保存・実行」として開示する。
2. 開発者または第三者へのデータ送信・販売・広告利用・人による閲覧がないことを、公開するバージョンで確認する。
3. Limited Use の認証は、[プライバシーポリシー](../privacy-policy.md) と実装に一致する場合だけ行う。

根拠: 設定は Chrome の同期ストレージで扱い、開発者サーバーは使用しない。詳細は [プライバシーポリシー](../privacy-policy.md) を参照する。
