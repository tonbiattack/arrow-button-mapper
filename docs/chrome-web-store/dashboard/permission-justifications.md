# Permissions justification

Developer Dashboard に表示された権限ごとに、該当する文面だけを貼り付ける。

## `storage`

ユーザーが登録した URL パターン、左右キーに対応する CSS セレクタ、拡張機能の有効・無効状態を Chrome の同期ストレージに保存するために使用します。これらはユーザーが設定したページ操作を実行、編集、エクスポート、インポートするためだけに使用します。

## `tabs`

ポップアップから、ユーザーが現在開いているタブで「操作を記憶」を開始するために使用します。記憶開始時に限り、対象タブへローカルのメッセージを送ります。

## `http://*/*` と `https://*/*` のページアクセス

ユーザーが登録したページで左右矢印キーに対応する要素をクリックするため、またはユーザーが開始した「操作を記憶」で選択したリンク・ボタンから CSS セレクタを作るために使用します。Chrome の内部ページ、Chrome Web Store、iframe は対象にしません。ページ内容や閲覧履歴を外部送信しません。
