# Arrow Button Mapper プライバシーポリシー

最終更新日: 2026-09-19

Arrow Button Mapper（以下「本拡張機能」）は、ユーザーが指定した Web ページ上のリンクまたはボタンを、キーボードの ← / → キーで操作できるようにする Chrome 拡張機能です。

## 取り扱う情報

本拡張機能は、ユーザーが設定した URL パターン、CSS セレクタ、拡張機能の有効・無効状態を Chrome の同期ストレージに保存します。ユーザーが「操作を記憶」を開始した場合に限り、現在のページの URL と、ユーザーがクリックしたリンクまたはボタンから作成した CSS セレクタを設定として保存します。

本拡張機能は、設定済みの操作を実行するために、対象ページ上で左右矢印キーと設定済み CSS セレクタを処理します。入力欄や編集可能な領域での通常のキー操作は対象にしません。

## 利用目的

上記の情報は、本拡張機能の単一目的である、ユーザーが指定したページ操作の記憶・実行・編集・設定移行のためだけに利用します。

## 共有と第三者提供

開発者は、閲覧履歴、ページ内容、URL パターン、CSS セレクタ、または設定内容を収集・送信・販売・共有しません。広告、分析、追跡目的の外部サービスも使用しません。

設定は Chrome の同期ストレージ機能を通じて、ユーザー自身の Chrome プロファイル間で同期される場合があります。この同期は Chrome の設定に従って行われ、開発者のサーバーを経由しません。

ユーザーが設定をエクスポートした場合、JSON ファイルはユーザーが選択した保存先にのみ作成されます。インポートする JSON ファイルは、ユーザーが選択したものだけを読み取ります。
