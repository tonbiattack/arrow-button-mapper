# ストア用スクリーンショットの撮影

Chrome Web Store に登録するスクリーンショットは、公開するバージョンの実際の UI を示す必要があります。画像は 640 × 400 または 1280 × 800 ピクセルの PNG を使用します。

## 撮影する画面

1. Chrome で `chrome://extensions` を開き、Arrow Button Mapper を再読み込みします。
2. 任意の通常の Web ページを開き、ツールバーの Arrow Button Mapper を開きます。
3. ポップアップ全体が読めるように撮影します。特に「操作を記憶」と「設定の移行」が分かる状態にします。
4. 640 × 400 または 1280 × 800 の、24 ビット PNG にします。透明度は使用しません。必要なら、Chrome の画面を含めて横長で撮影し、ポップアップを中央に配置します。

## 保存先

撮影したファイルは `assets/screenshots/` に保存します。公開前に、スクリーンショットが最新の UI・名称・説明と一致していることを確認してください。

現在の掲載用ファイルは、すべて 1280 × 800・24 ビット PNG です。

- `assets/screenshots/1.png` — 有効化、設定移行、操作記憶
- `assets/screenshots/2.png` — 新しい操作ペアの登録
- `assets/screenshots/3.png` — 登録済みの操作ペアの編集・削除

Chrome Web Store の自動操作はこの環境では制限されるため、最終的な実機撮影とダッシュボードへのアップロードは手動で行います。

これらの 3 枚は、公開するバージョンの実機 UI を横長の規格サイズに整形したものです。Chrome Web Store へはこの中から 1〜3 枚をアップロードします。
